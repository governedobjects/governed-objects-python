# Contributing

Thank you for your interest. Bug reports, questions and proposals are
welcome through GitHub issues, and code contributions are welcome through
pull requests.

Contributions are accepted under the Apache License, Version 2.0
(Section 5). Each commit must carry a Developer Certificate of Origin
sign-off (`git commit -s`), certifying that you have the right to submit
it under that license. The certificate text is at
https://developercertificate.org/.

Proposed changes to the Governed Objects Specification itself go to the
specification repository; see
https://github.com/governedobjects/governed-objects-spec/blob/main/GOVERNANCE.md.

Please report security issues privately to security@governedobjects.com,
not in public issues.
